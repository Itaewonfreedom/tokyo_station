# 🚉 도쿄역 철도 시뮬레이터 (Tokyo Station Rail Yard Simulator)

기차를 사랑하는 아기를 위한 **도쿄역 선로 3D 시뮬레이션**입니다.
위성사진 속 도쿄역(마루노우치 적벽돌 역사 + 청록색 지붕 승강장 + 나란한 선로들)을
Three.js로 재현하고, 야마노테선 E235를 비롯한 열차들이 쉴 새 없이 드나듭니다.

## 실행 방법

`index.html` 파일 하나만 브라우저에서 열면 됩니다. (설치 불필요, Three.js는 CDN 로드)

```bash
# 더블클릭으로 열거나, 간단한 서버로:
python3 -m http.server 8000
# → http://localhost:8000
```

## 등장 열차

| 열차 | 외형 | 동작 |
|---|---|---|
| 야마노테선 E235 ×4 | **실사 텍스처 아틀라스** (측면 2종·전면·대차·하부기기) | 진입 → 정차(문 열림 합성 텍스처) → 발차 멜로디 → 출발 |
| 케이힌토호쿠선 E233 | 하늘색 (절차 텍스처) | 〃 |
| 츄오선 E233 | 주황색 (절차 텍스처) | 〃 |
| 도카이도 신칸센 | 흰색+파랑 띠, 긴 코 | 〃 + 동쪽 선로에 주박 편성 1대 |

## 선로망과 운행 관리

- 역 구내 **10선**이 양쪽 분기기 사다리(S-커브 턴아웃)를 지나 **본선 5선**으로
  합류하고, 본선은 화면 끝(±760m)까지 이어집니다.
- 본선은 여러 열차가 공유하므로 **폐색(block) 디스패처**가 진입·진출 권한을
  관리합니다. 선행 열차가 분기기 구간을 완전히 빠져나가기 전에는 다음 열차가
  들어오지 못하고, 출발선이 막혀 있으면 문을 연 채 대기합니다 → 충돌 불가능.
- 각 본선 양 끝의 **신호기**가 폐색 상태를 실시간 표시(녹/적)합니다.
- E235 실사 아틀라스는 HTML에 base64로 내장되어 `file://`로 열어도 동작합니다.
  (원본: `textures/e235_atlas.png`)

## 조작

- **드래그 / 휠 / 핀치** — 시점 회전·확대 (터치 지원)
- **🚆 따라가기** — 달리는 기차를 자동 추적 (누를 때마다 다음 기차)
- **🛰️ 위성** — 위성사진과 같은 부감 구도
- **🚉 승강장 / 🏙️ 전경** — 프리셋 시점
- **🌙 낮/밤** — 창문 불빛·별·달이 켜지는 야경
- **🔇/🔊 소리** — 도착 차임, 출발 멜로디, 문 닫힘 경고음 (합성음, 기본 꺼짐)
- **기차 터치** — 빵빵! 경적 🚆💨
- 키보드: `F` 따라가기, `T` 낮/밤, `1/2/3` 시점

## 저사양 지원

우측 하단 **저사양 / 보통 / 고화질** 버튼:

- **저사양** — 그림자 끔, 해상도 0.7×, 가선·전주 숨김, 안개 거리 축소
- **보통** — 그림자 1024, 해상도 1× (모바일 기기에서 자동 선택)
- **고화질** — 그림자 2048, 네이티브 해상도

그 외 최적화: 침목·기둥 InstancedMesh(드로우콜 1회), 외부 에셋 없이
캔버스 절차 텍스처만 사용, 차량 측면을 텍스처 1장으로 표현(문 열림은 텍스처 교체).
