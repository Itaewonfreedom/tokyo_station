# 🚉 도쿄역 철도 시뮬레이터 (Tokyo Station Rail Yard Simulator)

기차를 사랑하는 아기를 위한 **도쿄역 선로 3D 시뮬레이션**입니다.
위성사진 속 도쿄역(마루노우치 적벽돌 역사 + 청록색 지붕 승강장 + 나란한 선로들)을
Three.js로 재현하고, 야마노테선 E235를 비롯한 열차들이 쉴 새 없이 드나듭니다.

## 실행 방법

`index.html` 파일 하나만 브라우저에서 열면 됩니다. (설치 불필요, Three.js는 CDN 로드)

```bash
# 더블클릭으로 열거나, 간단한 서버로:
python3 -m http.server 8000
# → http://localhost:8000
```

## 등장 열차 (실제 도쿄역 배선 기준)

| 열차 | 외형 | 운행 형태 |
|---|---|---|
| 야마노테선 E235 ×3 | **실사 텍스처 아틀라스** (측면 2종·전면·지붕·대차·하부기기) | 통과 운행 — 같은 선로에 2편성이 폐색 간격으로 연속 운행 |
| 케이힌토호쿠선 E233 ×2 | 하늘색 | 통과 운행 |
| 우에노도쿄라인 E231 ×2 | 주황+청록 투톤 (도카이도본선) | 통과 운행 |
| 츄오선 쾌속 E233 | 주황색 | **두단식 종착** — 북쪽에서 진입, 차막이 앞 정차 후 되돌림 |
| 도카이도 신칸센 N700 | 흰색+파랑 띠, **로프트 노즈** | **종착** — 남쪽 진입·되돌림 + 주박선에 1편성 유치 |
| 도호쿠 신칸센 E5 하야부사 | 청록+분홍 띠 도장, **13m 덕빌 로프트 노즈**(단면 26×26 로프트, 캐노피·노즈 스커트) | **종착** — 북쪽 진입·되돌림 |

## 선로망과 운행 관리

- 실제 배선표 기준 서→동 배열: 츄오선(종착 2선) → 케이힌토호쿠/야마노테 4선 →
  우에노도쿄라인 2선 → 도카이도 신칸센(종착 3선) → 도호쿠 신칸센(종착 2선),
  섬식 승강장 7면.
- 역 구내는 15선(폭 61m)으로 뚱뚱하지만, 목(throat)을 지나며 **북쪽 10선·남쪽
  8선의 좁은 회랑**으로 수렴해 화면 끝(±760m)까지 이어집니다. 종착선은
  차막이(buffer stop)에서 끝나 남북 본선 구성이 비대칭입니다.
- **폐색(block) 디스패처**: 본선 진입·진출 블록 + 승강장 점유 블록을 예약제로
  관리해 같은 선로의 후속 열차는 선행 열차가 빠져나가야 진입합니다 → 충돌 불가능.
  종착 열차는 되돌릴 때 전조등/후미등이 자동으로 바뀝니다.
- 목 입구의 **신호기**가 블록 상태를 실시간 표시(녹/적)합니다.
- 카메라가 건물 안으로 들어가거나 추적 중인 열차를 가리면 해당 건물·지붕이
  자동으로 투명해집니다.
- E235 실사 아틀라스는 HTML에 base64로 내장되어 `file://`로 열어도 동작합니다.
  (원본: `textures/e235_atlas.png`)

## 화면과 놀이 (만 3세 전후 + 부모)

아이가 글을 읽지 않아도 쓸 수 있게, 아이가 보는 화면에는 글자가 없습니다.

- **▶ 한 번 누르면 시작** — 뒤에서는 이미 기차가 달리고 있고, 이 탭으로 소리가 켜집니다.
  첫 화면부터 한 대는 승강장에 서 있고 한 대는 들어오는 중입니다.
- **아래 기차 카드** — 실제 3D 모델을 그대로 렌더링한 그림입니다. 누르면 그 기차를
  따라갑니다. 지금 역에 없는 기차는 그림이 흐려지고, 도착까지 남은 시간이
  동그라미로 차오릅니다(그 기차를 조금 일찍 부르되, 선로 점유 규칙은 그대로
  지킵니다). 맨 앞 카드(카메라 그림)는 **자동 관람**입니다.
- **시점 버튼** (기차를 고르면 나타남): 자동 · 선두부 · 옆에서 달리기 ·
  승강장 눈높이 · 운전석. 모든 시점은 실제 진행 방향의 선두 기준이라,
  종착역에서 되돌아 나갈 때는 반대편 끝으로 자연스럽게 날아갑니다.
- **자동 관람** — 들어오는 열차 → 문 열림·승하차 → 발차까지 한 열차의 이야기를
  끝까지 보여준 뒤 다음 볼거리로 넘어갑니다(몇 초마다 바뀌지 않음). 시점이 바뀔 때는
  순간이동 대신 부드럽게 날아가고, 먼 거리는 살짝 떠올라 넘어갑니다.
- **차장 놀이 (초록 ▶ 버튼)** — 보고 있는 열차가 승강장에 서면 버튼이 나타납니다.
  - 승객이 타는 동안: 회색 + 초록 링이 차오름 (승강장에서 사람들이 문으로 걸어가는 게 보임)
  - 앞 구간이 막혀 있으면: 버튼의 신호등이 빨갛게 깜빡임
  - 준비되면: 초록으로 두근두근 → 누르면 호루라기 → 발차 멜로디 → 문 닫힘 → 출발
  - 아이가 누르지 않아도 25초 뒤에는 스스로 출발합니다. 자동 관람 중에는
    누르지 않아도 평소처럼 출발합니다.
- **문이 실제로 열립니다** — 승강장 쪽 문마다 불 켜진 틈이 벌어지고, 사람이 내리고 탑니다.
- **경적 버튼 (주황)** / **기차를 직접 터치** — 그 기차의 경적 + 전조등 번쩍.
  손가락이 조금 빗나가도 가장 가까운 기차가 잡히고, 겹쳐 있으면 앞 기차가 우선입니다.
  기차를 터치하면 그 기차를 따라갑니다.
- **드래그 / 핀치** — 카메라를 직접 움직여도 기차를 계속 따라가며, 자동 연출이
  끼어들지 않습니다. 위에 뜨는 **눈 버튼**으로 관람에 복귀합니다(60초간 손대지 않아도 복귀).
- **가족 캐릭터를 터치하면** 폴짝 뛰며 인사합니다. 유튜브 채널 링크는 부모 설정으로 옮겼습니다.
- 왼쪽 위: 소리 켜기/끄기, 낮 → 늦은 오후 → 밤 (아이콘은 다음 시간대를 보여 줌).
- **부모 설정 (오른쪽 위 톱니, 길게 누르기)** — 음량, 안내 음성, 화질, 언어(한국어/日本語),
  전체 화면, 유튜브 채널. 소리·음량·음성·화질·언어·낮밤은 브라우저에 기억됩니다.
- **짧은 안내 음성** (브라우저에 한국어/일본어 음성이 있을 때만) — 보고 있는 열차에 대해서만,
  한 번에 하나씩, 같은 말은 반복하지 않습니다. 예: "야마노테선 들어와요", "출발 진행!",
  "문이 닫힙니다".
- 키보드(부모용): `1–5` 시점, `Space` 출발, `H` 경적, `N` 시간대, `M` 소리,
  `←/→` 기차 고르기, `Esc` 관람 복귀/자동.
- **손대지 않으면 UI가 옅어짐** — 7초 동안 입력이 없으면 카드·버튼이 부드럽게 흐려집니다.
  흐린 상태의 첫 터치는 UI만 깨우고 버튼이나 기차 터치로 처리되지 않습니다.
  직접 조작 중이거나 부모 설정이 열려 있으면 흐려지지 않습니다.
- 보는 동안 화면이 꺼지지 않도록 Wake Lock을 사용합니다 (지원 기기).

## 사운드

모든 소리는 파일 없이 WebAudio로 합성합니다.

- **공간 음향** — 소리마다 카메라 기준 좌우 위치(스테레오)와 거리 감쇠가 적용되어,
  보고 있는 기차의 소리가 크게 들립니다. 컨볼루션 리버브로 역 구내의 울림,
  컴프레서로 여러 소리가 겹쳐도 찢어지지 않게 했습니다.
- **주행음** — 카메라 근처의 기차마다 연속 음성: 속도에 따라 변하는 레일 굴림음 +
  VVVF 인버터음(가속 시 "우우웅↗", 제동 시 "↘우웅", 타행 시 조용). 신칸센은
  속도² 에 비례하는 바람 소리가 더해집니다.
- **가땅고똥** 레일 이음매 소리, 정차 직전 **브레이크 끼익**, 정차 후 **푸슈-** 공기음
- 벨 음색의 **도착 차임 / 문 열림·닫힘 차임 / 발차 멜로디**, 차장 **호루라기**
- **보고 있는 열차가 주인공** — 주행음은 보고 있는 열차 + 가까운 2대만 내고 나머지는
  작게, 역 방송(차임·멜로디)은 보고 있는 열차 것만 들립니다. 경적은 연타해도 겹치지 않습니다.
- 낮에는 은은한 도시 소음과 **참새 소리**
- 탭이 숨겨지면 오디오를 일시 정지해 배터리를 아낍니다.

## 그래픽

- **차종별 차체 단면** — 모든 열차가 같은 상자+원호 지붕을 쓰던 구조를 없애고,
  `PROFILES`에 차종별로 폭·밑단 폭(すそ絞り)·측벽 높이·어깨 곡률·지붕 크라운·차량 길이·
  대차 간격을 따로 정의했습니다. 형상 캐시 키도 프로필 단위입니다.
  - **E235**: 가운데가 넓고 평평한 지붕, 양쪽 어깨에서 완만하게 내려오는 단면
    (지붕 최고점이 측벽 위로 약 0.3m, 레일면 기준 약 3.6m).
  - **E233 / E231**: E235보다 조금 더 둥근 어깨. 츄오선(주황)·우에노도쿄라인(주황+녹색)은
    그림으로 그린 임시 차체 대신 실사 E233 사진의 띠 색만 바꿔서 사용합니다.
  - **N700 / E5 선두차**: 중간차 끝에 노즈를 덧붙이던 구조를 없애고, 선두차 한 량을 통째로
    만듭니다. E5 선두차 26.5m(노즈 15m), N700 선두차 27.35m(노즈 10.7m), 중간차 25m입니다.
    코끝, 노즈, 노즈 중간, 운전실 앞, 운전실, 객실 단면을 키 단면으로 정의하고,
    폭(상면)과 높이(측면)를 따로 단조 보간해서 이어 붙였습니다. 객실 단면은 중간차와 같습니다.
    - E5: 길고 낮은 덕빌 노즈와 차체 곡면에 녹아든 운전실 캐노피.
    - N700: 짧은 노즈와 에어로 더블윙 능선.
    - **편성 도색 통일**: 하야부사는 객차 사진 아틀라스가 기준입니다. 선두차 객실 구간은 같은 모델 높이에서
      아틀라스 픽셀을 그대로 샘플링하고(분홍 띠 2.21–2.36m, 창 2.48–2.88m, 흰색/하부 경계 1.30m),
      노즈의 도색선은 단면 비율을 따라 흘러내려 객실 구간에서 그 높이에 도달합니다.
      N700은 선두차 객실 규칙(`N700_LIV`)을 기준으로 객차 측면 텍스처를 같은 규칙에서 따로 생성합니다
      (파란 띠·보조선·창 높이와 둥근 모서리·문·흰색/하부색·광택·야간 창 발광 공통).
    - 앞유리·전조등·도색 경계·패널선·객실 창·출입문은 형상 좌표에서 직접 칠합니다.
      유리는 곡면과 같은 면에 있고 반사만 달라서, 예전의 늘린 반구형 유리는 없습니다.
    - 선두차·중간차 길이, 대차 위치, 몸체 모양 외부 가림막, 편성 길이, 정차 위치, 추적 기준,
      운전석 시점이 모두 차량별 길이를 씁니다.
  - 전면 윤곽(`makeCabFace`)이 차체 단면에서 바로 만들어져 지붕과 전면 사이에 틈이나 돌출이
    없습니다. 전조등 위치도 차종별로 다릅니다(E235 상단 모서리, E233 하단).
  - 냉방기는 평평한 지붕 위에 올린 장비로, 팬터그래프는 지붕 위 애자에서 가선 높이(6.0m)까지
    올라가도록 따로 배치했습니다. 승강장 높이도 차량 바닥 높이에 맞췄습니다.
- **건물 야간 조명** — 반복되던 3종의 "켜진 창문" 텍스처를 없애고, 건물마다 고정 시드로 셰이더에서
  계산합니다. 주간 텍스처와 같은 창문 격자에서만 빛나고, 층 단위(1–3층 묶음)와 사무실 구역
  (창 3–6개) 단위로 켜지고 꺼집니다. 건물 성격(대부분 소등 / 일부 층만 / 바쁜 사무실 /
  저층 상가)과 색온도(3000–4500K)를 제한적으로 나눴고, 면마다 패턴이 다릅니다.
  매 프레임 다시 뽑지 않아 항상 같은 모습입니다.
- **밤 조명** — "기차가 잘 보이는 도시의 밤":
  - 승강장 지붕 아래 조명이 실제로 승강장 바닥, 차체 측면·전면, 대차와 선로를 비춥니다
    (그림자 없는 선형 광원 7개를 셰이더에서 계산). 역 구내 전체에는 은은한 보조광이 있고,
    마루노우치 역사 정면에는 투광 조명이 있습니다.
  - 차가운 달빛과 하늘빛(반구광)에 따뜻한 역 조명을 더했고, 밤 노출은 거의 낮추지 않습니다.
    중경 빌딩 외벽은 밤에 한 단계 어둡게, 원경은 밝은 도시 지평선과 안개로 정리합니다.
  - 객차 창문·전조등 광륜은 하얗게 날아가지 않도록 세기를 낮췄습니다.
  - 환경맵(반사)은 낮↔밤 사이를 하나의 렌더 타깃에 다시 필터링해 서서히 바뀝니다
    (예전에는 절반 지점에서 한 번에 바뀌어 반사가 튀었습니다).

- **선로 바닥** — 콘크리트 고가 상판 위에 선로마다 자갈 도상(어깨 경사 포함)을 깔고,
  도호쿠 신칸센은 콘크리트 슬래브 궤도로 구분했습니다. 승강장과 선로 사이 콘크리트는
  자갈로 덮지 않습니다.
  - 자갈은 각진 돌(30–65mm)을 절차적으로 채운 1.6m 타일입니다. 알베도, 노멀, 러프니스 맵을 쓰고
    금속성은 0입니다. 셰이더에서 두 단계 넓은 명암 변화를 더하고, 레일 아래 녹·브레이크 가루,
    침목 주변 접촉 음영을 넣습니다.
  - 멀리서는 평균 회색으로, 노멀은 거리에 따라 약하게, 칠한 침목은 미분 기반으로 부드럽게 해서
    반짝임을 줄였습니다.
  - PC 침목(0.9m 간격)과 60kg 레일 단면은 역 주변 330m 안에서만 3D입니다. 그 밖은 가벼운
    레일 단면과 칠한 침목을 씁니다. 높이: 도상 0.33, 침목 윗면·레일 밑면 0.36, 레일 윗면 0.53.

- **객차별 주행 진동** — 차체만 움직이고(상하·롤·피치), 대차·바퀴·팬터그래프는 레일 위에 그대로 있습니다.
  - 선로 위치에 고정된 궤도 틀림(고정 사인 합)과 25m 이음매 충격을 앞·뒤 대차에서 따로 읽습니다.
    그래서 같은 지점을 지나는 객차가 속도와 차간 거리만큼 시간차를 두고 차례로 반응합니다.
  - 이음매 충격은 감쇠 응답이고, 이음매 소리와 같은 트리거를 씁니다. 프레임마다 난수를 쓰지 않습니다.
  - 진폭은 수 mm(최대 약 2.6mm 통근 / 1.5mm 신칸센)이고, 기울기는 0.03° 안팎입니다.
    속도에 따라 포화하며, 신칸센이 더 안정적입니다. 곡선에서는 약간 기울고, 출발·제동 때는 살짝 앞뒤로 숙입니다.
    정차하면 부드럽게 가라앉습니다.
  - 위치·충돌·정차 계산은 레일 기준 프레임만 씁니다. 진동은 표시용 자식 노드에만 들어가고,
    추적 카메라는 흔들리지 않습니다. 30/60fps에서 같은 결과가 나오며 역방향 운행에서도 동작합니다.
- **접촉 그림자** — 차체와 대차 아래(레일 기준이라 진동과 어긋나지 않음), 승강장 기둥 밑에 부드러운 접촉 음영을 넣었습니다.
  태양 그림자 상자는 카메라 거리에 따라 6단계 크기에서 고르고(히스테리시스), 텍셀 단위로 고정해서 카메라가 움직여도 떨리지 않습니다.
- **감상 카메라** — 시점마다 FOV가 따로 있습니다(선두부 30°, 옆 32°, 승강장 46°, 전경 52°, 운전석 62°).
  그래서 망원 시점에서는 코가 왜곡되지 않고 뒤 차량도 작아지지 않습니다. 세로 화면에서는 자동으로 넓힙니다.
  위치·FOV·주시점이 함께 부드럽게 전환됩니다. 피사계심도·모션 블러·카메라 흔들림은 쓰지 않습니다.
- **유리와 차체 재질** — 객실 창은 각도에 따른 반사에 얕은 실내 깊이(시차로 보이는 좌석 윤곽, 안쪽 벽, 천장 조명)를 더했습니다.
  밤에는 객차마다 고정된 밝기 차이가 있어 균일하지 않지만 깜빡이지 않습니다.
  스테인리스, 도장, 유리, 고무의 거칠기와 금속성을 나눴습니다.
- **열차 반사 프로브** — 역 한가운데에서 열차를 뺀 128px 큐브맵을 한 번 찍어 모든 열차의 반사에 씁니다.
  그래서 지붕·빌딩이 비치고, 자기 반사나 구역 사이 튐이 없습니다.
  시간대가 바뀌는 동안에만 최대 0.5초에 한 번 다시 찍습니다. 저사양에서는 끕니다.
- **늦은 오후** — 낮고 따뜻한 해, 차가운 하늘빛 그늘, 긴 그림자. 오렌지 필터 없이 햇빛 받은 면만 따뜻합니다.
  승강장 조명은 약하게 먼저 켜집니다. 하늘, 환경맵, 조명, 안개, 창 발광이 하나의 블렌드로 낮↔오후↔밤 사이를 끊김 없이 넘어갑니다.

## 저사양 지원 / 최적화

우측 하단 **저사양 / 보통 / 고화질** 버튼:

- **저사양** — 그림자 끔, 해상도 0.7×, 가선·전주 숨김, 안개 거리 축소
- **보통** — 그림자 1024, 해상도 1× (모바일 기기에서 자동 선택)
- **고화질** — 그림자 2048, 네이티브 해상도, 야간 블룸

최적화:

- **드로우콜 약 1/3** (전경 시점 기준 848 → 약 270, 기차가 많이 보일수록 차이가 더 큼)
  - 열차 한 편성 = 약 17 드로우콜: 차량 몸체를 재질 슬롯별로 하나의 지오메트리로
    구워 `InstancedMesh`로 그립니다 (이전에는 차량 1량에 약 22개 메시)
  - 레일·가선·전주·승강장·안내판·신호기·역사 건물·빌딩을 재질별로 병합
    (z 구간별로 나눠 화면 밖 컬링은 유지)
- 60fps 상한의 프레임 페이싱 수정 — 60Hz 화면에서 프레임이 들쭉날쭉 빠지던 문제 해결
- 4장의 사진 아틀라스를 병렬로 디코딩하고, 셰이더를 미리 컴파일한 뒤 시작 버튼 활성화
- 침목·기둥·소품 InstancedMesh, 외부 에셋 없이 캔버스 절차 텍스처만 사용

개발용: `index.html?debug` 로 열면 `window.__sim` (trains, rig, `run(sec)` 빨리감기,
`simulate(sec)`, `timeScale`, `pickTrain(x,y)` 등) 이 노출됩니다.
