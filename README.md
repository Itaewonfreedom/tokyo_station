# 🚉 도쿄역 철도 시뮬레이터 (Tokyo Station Rail Yard Simulator)

기차를 사랑하는 아기를 위한 **도쿄역 선로 3D 시뮬레이션**입니다.
위성사진 속 도쿄역(마루노우치 적벽돌 역사 + 청록색 지붕 승강장 + 나란한 선로들)을
Three.js로 재현하고, 야마노테선 E235를 비롯한 열차들이 쉴 새 없이 드나듭니다.

## 실행 방법

`index.html` 파일 하나만 브라우저에서 열면 됩니다. (설치 불필요, Three.js는 CDN 로드)

```bash
# 더블클릭으로 열거나, 간단한 서버로:
python3 -m http.server 8000
# → http://localhost:8000
```

## 등장 열차 (실제 도쿄역 배선 기준)

| 열차 | 외형 | 운행 형태 |
|---|---|---|
| 야마노테선 E235 ×3 | **실사 텍스처 아틀라스** (측면 2종·전면·지붕·대차·하부기기) | 통과 운행 — 같은 선로에 2편성이 폐색 간격으로 연속 운행 |
| 케이힌토호쿠선 E233 ×2 | 하늘색 | 통과 운행 |
| 우에노도쿄라인 E231 ×2 | 주황+청록 투톤 (도카이도본선) | 통과 운행 |
| 츄오선 쾌속 E233 | 주황색 | **두단식 종착** — 북쪽에서 진입, 차막이 앞 정차 후 되돌림 |
| 도카이도 신칸센 N700 | 흰색+파랑 띠, **로프트 노즈** | **종착** — 남쪽 진입·되돌림 + 주박선에 1편성 유치 |
| 도호쿠 신칸센 E5 하야부사 | 청록+분홍 띠 도장, **13m 덕빌 로프트 노즈**(단면 26×26 로프트, 캐노피·노즈 스커트) | **종착** — 북쪽 진입·되돌림 |

## 선로망과 운행 관리

- 실제 배선표 기준 서→동 배열: 츄오선(종착 2선) → 케이힌토호쿠/야마노테 4선 →
  우에노도쿄라인 2선 → 도카이도 신칸센(종착 3선) → 도호쿠 신칸센(종착 2선),
  섬식 승강장 7면.
- 역 구내는 15선(폭 61m)으로 뚱뚱하지만, 목(throat)을 지나며 **북쪽 10선·남쪽
  8선의 좁은 회랑**으로 수렴해 화면 끝(±760m)까지 이어집니다. 종착선은
  차막이(buffer stop)에서 끝나 남북 본선 구성이 비대칭입니다.
- **폐색(block) 디스패처**: 본선 진입·진출 블록 + 승강장 점유 블록을 예약제로
  관리해 같은 선로의 후속 열차는 선행 열차가 빠져나가야 진입합니다 → 충돌 불가능.
  종착 열차는 되돌릴 때 전조등/후미등이 자동으로 바뀝니다.
- 목 입구의 **신호기**가 블록 상태를 실시간 표시(녹/적)합니다.
- 카메라가 건물 안으로 들어가거나 추적 중인 열차를 가리면 해당 건물·지붕이
  자동으로 투명해집니다.
- E235 실사 아틀라스는 HTML에 base64로 내장되어 `file://`로 열어도 동작합니다.
  (원본: `textures/e235_atlas.png`)

## 조작

- **드래그 / 휠 / 핀치** — 시점 회전·확대 (터치 지원)
- **🚆 따라가기** — 달리는 기차를 자동 추적 (누를 때마다 다음 기차)
- **🎥 운전석** — 따라가는 기차의 운전석에 타서 앞을 바라보는 시점. 종착역에서
  되돌아 나갈 때는 반대편 운전석으로 옮겨 탑니다
- **🎮 게임** — 이름이 나온 기차를 찾아 터치 (정답이면 별이 팡!)
- **🛰️ 위성** — 위성사진과 같은 부감 구도
- **🚉 승강장 / 🏙️ 전경** — 프리셋 시점
- **🌙 낮/밤** — 창문·객차 창·승강장 불빛, 달빛, 별이 켜지는 야경
- **🔇/🔊 소리** — 시작 화면의 "소리 켜고 시작"으로 바로 켤 수도 있어요
- **⛶ 전체화면** — 지원하는 브라우저에서만 표시
- **기차 터치** — 빵빵! 경적 🚆💨 (통근형 / 신칸센 음색이 다름)
- 키보드: `F` 따라가기, `C` 운전석, `G` 게임, `T` 낮/밤, `M` 소리, `L` 언어,
  `1/2/3` 시점, `Esc` 운전석 나가기
- 언어·화질·소리·낮밤 설정은 브라우저에 기억됩니다. 보는 동안 화면이 꺼지지
  않도록 Wake Lock을 사용합니다 (지원 기기).

## 사운드

모든 소리는 파일 없이 WebAudio로 합성합니다.

- **공간 음향** — 소리마다 카메라 기준 좌우 위치(스테레오)와 거리 감쇠가 적용되어,
  보고 있는 기차의 소리가 크게 들립니다. 컨볼루션 리버브로 역 구내의 울림,
  컴프레서로 여러 소리가 겹쳐도 찢어지지 않게 했습니다.
- **주행음** — 카메라 근처의 기차마다 연속 음성: 속도에 따라 변하는 레일 굴림음 +
  VVVF 인버터음(가속 시 "우우웅↗", 제동 시 "↘우웅", 타행 시 조용). 신칸센은
  속도² 에 비례하는 바람 소리가 더해집니다.
- **가땅고똥** 레일 이음매 소리, 정차 직전 **브레이크 끼익**, 정차 후 **푸슈-** 공기음
- 벨 음색의 **도착 차임 / 발차 멜로디 / 문 닫힘 경고음** — 승강장 방송처럼 멀면 작게
- 낮에는 은은한 도시 소음과 **참새 소리**
- 탭이 숨겨지면 오디오를 일시 정지해 배터리를 아낍니다.

## 그래픽

- **하늘 반사 조명(IBL)** — 하늘을 미리 필터링한 환경맵으로 레일·유리 빌딩·차체가
  하늘을 반사합니다. 하늘에는 해 광륜, 밤에는 달빛 광륜이 있습니다.
- **선명한 그림자** — 그림자 영역이 보고 있는 곳을 따라다니며 확대 정도에 맞춰
  크기가 바뀌고, 텍셀 단위로 스냅되어 가장자리가 떨리지 않습니다.
- **야경** — 객차 창문이 실제 사진 텍스처의 유리 부분만 골라 불이 켜지고,
  승강장 바닥에 조명 웅덩이가 생기며, 전조등/후미등에 광륜이 생깁니다.
  고화질 모드에서는 밤에만 블룸(빛 번짐)이 켜집니다.
- 차량이 곡선에서 살짝 기울고 속도에 따라 미세하게 흔들립니다.

## 저사양 지원 / 최적화

우측 하단 **저사양 / 보통 / 고화질** 버튼:

- **저사양** — 그림자 끔, 해상도 0.7×, 가선·전주 숨김, 안개 거리 축소
- **보통** — 그림자 1024, 해상도 1× (모바일 기기에서 자동 선택)
- **고화질** — 그림자 2048, 네이티브 해상도, 야간 블룸

최적화:

- **드로우콜 약 1/3** (전경 시점 기준 848 → 약 270, 기차가 많이 보일수록 차이가 더 큼)
  - 열차 한 편성 = 약 17 드로우콜: 차량 몸체를 재질 슬롯별로 하나의 지오메트리로
    구워 `InstancedMesh`로 그립니다 (이전에는 차량 1량에 약 22개 메시)
  - 레일·가선·전주·승강장·안내판·신호기·역사 건물·빌딩을 재질별로 병합
    (z 구간별로 나눠 화면 밖 컬링은 유지)
- 60fps 상한의 프레임 페이싱 수정 — 60Hz 화면에서 프레임이 들쭉날쭉 빠지던 문제 해결
- 4장의 사진 아틀라스를 병렬로 디코딩하고, 셰이더를 미리 컴파일한 뒤 시작 버튼 활성화
- 침목·기둥·소품 InstancedMesh, 외부 에셋 없이 캔버스 절차 텍스처만 사용

개발용: `index.html?debug` 로 열면 `window.__sim` (renderer, trains, `simulate(sec)`,
`timeScale`, `view(...)`) 이 노출됩니다.
